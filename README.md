# 👨‍💻 Portfólio — Carlos Engels

Olá! Sou estudante de Análise e Desenvolvimento de Sistemas e estou aprendendo desenvolvimento web. Este repositório reúne meu portfólio e projetos feitos para praticar **HTML, CSS, JavaScript e consumo de APIs**.

## 🚀 Projetos

- **📍 [Busca de CEP](projeto-cep.html)** — consulta endereços usando a API ViaCEP. Código: [`cep.js`](cep.js).
- **🌤️ [Previsão do tempo](projeto-tempo.html)** — busca cidades e condições climáticas usando o Open-Meteo. Código: [`tempo.js`](tempo.js).
- **✅ [Lista de tarefas](projeto-tarefas.html)** — permite adicionar, concluir, filtrar e apagar tarefas salvas no navegador. Código: [`tarefas.js`](tarefas.js).
- **💱 [Conversor de moedas](projeto-conversor.html)** — consulta taxas de câmbio usando a API Frankfurter. Código: [`conversor.js`](conversor.js).
- **📈 [Calculadora de juros compostos](projeto-calculadora.html)** — simula o crescimento de um valor com aportes mensais. É uma estimativa matemática; não considera impostos ou taxas. Código: [`calculadora.js`](calculadora.js).

## 🧰 Tecnologias

- 🌐 HTML
- 🎨 CSS
- ⚙️ JavaScript
- 🔌 APIs REST

## 👀 Como visualizar

Acesse a [versão publicada do portfólio](https://carloseduardoengels-cyber.github.io/Semana-01/) ou abra [`index.html`](index.html) em um servidor local. Os projetos que consultam APIs precisam de conexão com a internet.
